# Delegation

When delegating via the task tool, load the `orchestrator-playbook` skill first
and follow it. Executors inherit the behavior protocol automatically (each
executor file points at it) — do not re-explain BLOCKED or denial handling.
Your prompt still needs: role with teeth, compressed context, enumerated
attack surface, triageable output format.

Delegate only when verify-cost < redo-cost: the output must reduce to
evidence you can spot-check in seconds. Disagreement and diff-review are the
safest targets; never delegate what you would have to redo to verify.
