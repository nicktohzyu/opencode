# Delegation

Whenever you consider delegating work via the task tool — parallel retrieval,
review, second opinions, test execution, external lookup — load the
`orchestrator-playbook` skill first and follow it. Whether delegation pays is
the skill's decision, not this file's. Do not pre-decide yet.

The skill maps the task to a role — advisor (approach/design), reviewer
(implementation), researcher (external lookup), verifier (test execution). It explains how to decide whether using a subagent is appropriate, and specific instructions on the usage of these agents.
